# Channel Profile: docs (v1)

- Scope: long-form written documentation — wiki pages, READMEs, design
  docs, runbooks.
- Sample basis: 0 verified-human samples yet `[unverified: no corpus]`.

- Sentence budget: no fixed cap — length serves the structure.

## Traits (seed hypotheses)

1. Purpose first — the opening states what this page is for and who
   reads it; no warm-up.
2. Complete sentences, full structure — `##` headings, tables, and lists
   are allowed here, unlike comments; fragments only for data.
3. Numbers with baselines, as everywhere — a metric in a doc still needs
   its "compared to what".
4. Imperative, present tense for instructions ("Run ...", not "You
   should run ...", not "It is recommended to ...").
5. No marketing voice — no "powerful", "seamless", "easy"; the doc's
   value is in its accuracy.
6. Sections end on the reader's next action or the next question the
   page answers — no trailing filler.
